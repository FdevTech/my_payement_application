# my_payement_application

## Getting started

### Requirements
- Xcode with Swift 6.4 or later
- iOS 17.0+

### Setup
1. Clone the project:
   ```bash
   git clone https://github.com/FdevTech/my_payement_application.git
   ```
2. Open Xcode and choose **File → Open…**
3. Select `my_payement_application/MyApplicationApp.xcodeproj`
   (or double-click it in Finder).
4. Xcode will automatically fetch the [My_Ledger_SDK](https://github.com/FdevTech/My_Ledger_SDK)
   package (version `1.0.0-alpha`). Wait for "Resolving Package Graph" to finish.
5. Select an iOS 17+ simulator and press **Run** (⌘R).

### Troubleshooting
If package resolution fails, use **File → Packages → Reset Package Caches**,
then **File → Packages → Resolve Package Versions**.
